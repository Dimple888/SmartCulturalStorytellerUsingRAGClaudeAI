🏗️ Technical Architecture

Frontend Stack

  • HTML5 - Semantic markup and accessibility
  • CSS3 - Modern styling with responsive grid layout
  • Vanilla JavaScript - No dependencies, lightweight API integration
  • Fetch API - Modern async HTTP requests

Backend Stack

  • Spring Boot 3.2 - REST API framework
  • Spring AI 1.0-M1 - LLM integration with Claude Haiku
  • H2 Database - In-memory cultural text storage
  • Custom Vector Store - In-memory RAG implementation
  • AWS Polly (ready) - Text-to-speech synthesis

Data Flow

User Input → Form Validation → REST API Call → Backend Processing (RAG + Claude AI) → JSON Response → UI Rendering with Audio/Metadata

🔌 API Endpoints

All endpoints follow RESTful conventions and return JSON responses.

Story Management

POST /api/narrator/generate-story

Generate complete stories with scenes and narration

RAG Retrieval

GET /api/narrator/search-rag?query=query_text

Search vector store with semantic similarity

GET /api/narrator/cultural-text

Retrieve full Sundarakanda text

TTS Synthesis

POST /api/narrator/tts/synthesize

Synthesize text to speech with emotion mapping

GET /api/narrator/tts/voices

Get supported voice configurations

Content Filtering

GET /api/narrator/emotion/{emotion}

Filter chunks by Rasa (emotional tone)

GET /api/narrator/character/{character}

Filter scenes by character name

Vector Store Management

POST /api/narrator/load-sundarakanda

Load Sundarakanda text into vector store

GET /api/narrator/vector-store-stats

Get vector store statistics

🚀 Getting Started

Step 1: Start the Application

mvn clean spring-boot:run

Step 2: Open the Web Interface

http://localhost:8080/

Step 3: Verify Connection

Click "Check Status" button in header - should show "● Connected"

Step 4: Load Sample Data

Go to 📊 Vector Store tab and click "Load Sundarakanda"

Step 5: Try a Feature

Go to any tab and click the main action button to test

✓ Demo mode is enabled by default

The application works without API keys for testing. For production with real Claude AI, set ANTHROPIC_API_KEY environment variable.
